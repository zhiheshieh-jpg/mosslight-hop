版本 **2.5.0**。包含独立保存进度的 2D 像素动作冒险与 3D 平台跳跃，两版均有森林、夜城、绯晶天宫和第四章「星穹实验室」。菜单中的「前往2D」「前往3D」可在两版之间切换。

## 角色、章节与解锁

两名普通角色为「GPT （同人Q版形象）」和「Claude」。GPT 使用用户提供的白紫龙娘参考形象；Claude 使用用户提供的橙色方块参考形象。2D 两者使用相同的普通碰撞与战斗数值，动画、预览和攻击配色随角色变化；3D 普通主角恢复为原来的白色竖立方块，角色通关身份仍分别记录。

| 阶段 | 条件 |
| --- | --- |
| 第一、第二章 | 默认开放 |
| 第三章 · 绯晶天宫 | 在当前版本累计通关前两章，顺序不限 |
| 第四章 · 星穹实验室 | GPT 和 Claude **各自**无辅助通关前三章，即六份独立角色记录 |
| 无敌模式 | 满足第四章前置条件后，由任一普通角色无辅助通关第四章 |
| 第三角色 · Δ0x7F_∴▒9 | 无敌模式已解锁且当前已开启时才可选择 |

一份角色通关记录要求整次挑战没有使用过无敌模式，也没有中途切换角色。中途关闭无敌或切回原角色，不会把这次挑战变成有效的普通通关；重新开始本关可开始新挑战。关卡内和暂停页禁止手动切换角色，只有返回选关页才能更换。Logo 形态关闭无敌时，会自动退回上一位普通角色，本次仍算辅助挑战。第三角色不参与普通解锁条件，也不能取得普通角色通关记录。

2D 与 3D 的角色通关、章节解锁和无敌偏好在同一账号中分别保存。旧版前三章通关与有效最好成绩会保留为历史记录，可保留第三章入口；历史记录无法识别当时使用的角色，因此不会自动给 GPT 或 Claude 补记通关，也不会直接解锁第四章或无敌模式。旧版已开启的无敌偏好，在未满足新版解锁条件时会关闭。两版使用同一个旅人账号，云存档保存在服务器；本机缓存用于断网恢复，跨设备使用账号和密码登录。

## 账号与云存档

首次进入会自动注册并登录，生成旅人账号和 6 位数字密码。菜单账号栏可以查看、复制账号密码，也可以输入其他账号登录；不存在的账号会自动创建。已有账号必须使用正确密码。没有手机号、邮箱或第三方账号绑定，也不要求复杂密码。

暂停页的“保存存档”会保存当前角色、位置、生命、收集、机关计时、开箱与攻击强化状态。选关页“继续存档”可恢复到暂停状态，再点击继续冒险。游戏每 15 秒自动保存，存档点、开箱、拾取强化和死亡时也立即保存。通关后清除对应关卡的进行中存档，保留账号通关记录。

账号数据保存在服务器 SQLite 数据库 `/var/lib/mosslight/account.sqlite3`，与静态版本目录分开，电脑或 API 重启、更新游戏均不会覆盖数据库。服务开机自启，每日生成经过完整性校验的备份；密码使用带盐 PBKDF2 哈希，服务器不保存明文密码。断网时保留账号对应的本机副本与待同步操作，网络恢复后上传。首次自动注册会导入当前浏览器的旧游戏进度；切换到已有账号以后以该账号的云端数据为准。

## 宝箱与攻击强化

每张 2D 地图有可互动宝箱，靠近后按 E、点击箱子，或点触屏“开箱”按钮。普通空箱显示“好像只是一个空箱子...”。每次重新开始关卡时随机选定恰好一个奖励箱，开箱后掉落攻击强化，接触拾取使普通斩击与反弹弹丸伤害翻倍。强化死亡或回存档点后消失，已打开、已领取的奖励不会因死亡重新发放；重新开始本关才重新抽取。存档会保留箱子抽取结果与强化状态。

## 2D 像素版 · 双星远行

横向卷轴关卡结合像素背景、多层视差、晨光、夜雨、云海夕照与洁净的未来实验室。普通角色可使用二段跳、光刃三连斩、冲刺闪避和弹丸反击。手机提供移动、跳跃、攻击与冲刺按钮，横屏可看到更多路线；切出浏览器会自动暂停。

| 操作 | 按键 |
| --- | --- |
| 移动 | A / D 或左右方向键 |
| 跳跃 / 二段跳 | 空格、W 或上方向键，空中再次按下 |
| 光刃三连斩 | 鼠标左键或 J，按住连续攻击 |
| 冲刺闪避 | 鼠标右键或 K / Shift |
| 暂停 / 继续 | Esc |
| 开箱 | 靠近按 E、点击箱子或触屏开箱 |
| 返回最近存档灯 | R |
| 音乐与音效 / 全屏 | M / F |
| 切换已解锁的无敌模式 | G，或菜单 / 暂停 / 游戏顶栏开关 |
| 无敌飞行 | A / D 左右，W / 上方向键 / 空格上升，S / 下方向键下降 |

| 关卡 | 路线 | 敌人（含首领） | 收集物 | 存档灯（含起点） |
| --- | --- | --- | --- | --- |
| 晨露之森 | 24 段主平台，11,668 世界像素 | 30 | 86 | 5 |
| 霓虹断层 | 32 段主平台，16,590 世界像素 | 41 | 115 | 7 |
| 绯晶天宫 | 42 段主平台，38,815 世界像素 | 112 | 181 | 1（仅起点） |
| 星穹实验室 | 48 段主平台，50,447 世界像素 | 130 | 209 | 5 |

击败关底首领并抵达右侧光门即可通关；普通敌人和收集物可以绕过。第三段斩击伤害与击退更强，光刃可反弹敌方弹丸。存档灯回复生命，击败普通敌人和首领都不会回复生命。前两章与实验室失败后返回最近存档，保留本局收集、分数与已击败的普通敌人，首领恢复初始状态；重开本关重置本局进度。

绯晶天宫包含晶刺、移动晶锯、垂直光束与塌落晶桥，仅保留起点存档。死亡或返回存档会重置本次挑战的敌人、首领、机关、收集和分数。首领「绯晶裁决者」使用冲锋与多种弹幕，半血后加速。

星穹实验室是一座完整运转的研究设施，路线经过无菌接驳舱、量子计算廊、聚变反应区和欧米伽主控室。实验室包含光束、晶锯、尖刺、塌落桥与补给存档，关底首领为「欧米伽主脑」。机关按固定物理时钟运行，暂停时冻结。

无敌模式解锁后，可在当前挑战中开关：免疫伤害、自由飞行，普通角色每次攻击清除当前可见画面内的敌人（包括首领）及屏内弹丸。关闭后恢复重力与普通攻击；若角色位于实体平台内部，会被移到安全表面。使用过无敌的挑战不计普通通关。

第三角色「Δ0x7F_∴▒9」以 OpenAI 标志为中心，带有旋转光针。它仅在无敌开启时可用，移动更快；光针接触敌人即可消灭敌人。右键 / K / Shift 可无限连续冲刺，每次冲刺清除当前可见画面内的敌人；左键 / J 触发自爆式全屏攻击。这里的“全屏”指当前可见游戏画面，屏外敌人保持原状；自爆是攻击效果，不会结束挑战。关闭无敌后退出该角色并恢复普通角色。

2D 版不依赖 Three.js。角色动作图集与四张背景使用内置 ImageGen 生成或编辑，提示词保存在 `dist/2d/assets/PROMPTS.json`；实验室另有 `dist/2d/assets/LAB-PROMPT.json`。Logo 使用有明确来源的 SVG 图形，地形、敌人、光针和战斗特效由 Canvas2D 绘制，音乐与音效由 WebAudio 合成。

## 3D 版

3D 版保留无战斗的机关平台跳跃：越过浮岛与测试平台，收集微光和珍藏，抵达圆形光门。四章均没有敌人、首领或攻击；普通角色选择与解锁规则和上文一致。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键，方向跟随镜头 |
| 环视 / 缩放 | 移动鼠标 / 滚轮 |
| 跳跃 | 空格 |
| 暂停并释放鼠标 | Esc |
| 继续并重新锁定鼠标 | 点击“继续冒险” |
| 视角复位 / 辅助转向 | C / Q、E |
| 回到最近存档点 | R |
| 切换已解锁的无敌模式 | G，或界面开关 |
| 无敌飞行 | WASD 水平移动，空格上升，Shift 下降 |
| Logo 角色无限冲刺 | 鼠标右键或 X，手机使用冲刺按钮 |

点击出发会请求全屏与鼠标锁定；浏览器需要用户点击才允许这些功能。若未获得锁定，可点击画面重试。返回选关退出全屏。手机使用左侧摇杆、跳跃按钮、空白区域单指环视与双指缩放；无敌开启时提供上升和下降控制。

森林包含 22 个平台和自转浮岛；都市包含 30 个平台与移动、塌落、光栅、旋转光臂、下压闸门和间歇平台。前两章有途中存档，失败保留已收集物品和积分。微光计 10 分、珍藏计 50 分，收集不影响通关；任意关全收集可解锁金色光环。

绯晶天宫包含 44 个平台、运动机关与完整云上宫殿。星穹实验室包含 50 个测试平台，场景由研究舱室、通道、设备与核心装置组成。两章均只有起点存档，失败后从起点重新挑战并重置本次收集和机关。

无敌解锁后提供机关免疫与自由飞行。第三角色「Δ0x7F_∴▒9」使用 SVG 几何标志、旋转光针和更快移动 / 无限冲刺；3D 继续保持无战斗规则，因此不提供 2D 的接触清敌、全屏攻击或自爆技能。关闭无敌后恢复普通角色、重力和碰撞。

## 本地运行与目录

安装 Node.js 20 或更新版本，在项目目录运行：

```sh
node server.mjs
```

默认打开 `http://127.0.0.1:4186/` 进入 2D；`http://127.0.0.1:4186/3d/` 进入 3D，两版可从菜单互跳。运行不需要安装依赖，素材和 Three.js 随源码提供；本地服务器启动后可离线游玩。ES 模块需要 HTTP 服务，请不要直接双击 HTML。

`server.mjs` 的默认展示路径与原始静态目录不同：开发源目录仍是 `dist/index.html` 对应 3D、`dist/2d/index.html` 对应 2D。直接用其他静态服务器托管 `dist/` 时，根路径是 3D，`/2d/` 是 2D；部署或编写浏览器测试时需使用对应路由。

| 文件 | 内容 |
| --- | --- |
| `dist/2d/characters.js` / `dist/2d/sprite-atlas.js` | 普通角色、Logo 角色配置与图集裁切 |
| `dist/2d/world.js` | 2D 物理、敌人、首领、战斗、光针与存档 |
| `dist/2d/sky-level.js` / `dist/2d/lab-level.js` | 2D 第三、第四章路线与机关 |
| `dist/2d/progression.js` | 2D 双角色进度、历史迁移与无敌解锁 |
| `dist/2d/game.js` | 2D 绘制、输入、角色动画、界面与合成音频 |
| `dist/2d/assets/` | 角色图集、四章背景、Logo SVG 与生成提示词 |
| `dist/game.js` / `dist/physics.js` | 3D 场景、角色、镜头、输入与固定步长物理 |
| `dist/palace-level.js` / `dist/palace-scene.js` | 3D 天宫路线与场景 |
| `dist/lab-level.js` / `dist/lab-scene.js` | 3D 实验室路线与场景 |
| `dist/progression.js` | 3D 独立双角色进度与无敌解锁 |
| `dist/orbit.js` / `dist/collection.js` | 镜头控制、收集与收藏等级 |
| `dist/vendor/` | Three.js r169、GLTFLoader、SVGLoader、BufferGeometryUtils 与许可证 |
| `models/MosslightAssets.blend` / `tools/build_assets.py` | 可编辑 Blender 模型与重建脚本 |
| `dist/assets/` | 3D 模型、ImageGen 贴图与 Logo SVG |
| `tools/release_source.py` | 生成公开代码浏览页和源码 ZIP |

使用 `blender --background --python tools/build_assets.py` 可重建模型；使用 `python tools/release_source.py` 可重新生成源码发布包。

## 检查方法

```sh
npm test
node qa/lab-route.mjs
node qa/lab3d-route.mjs
```

自动测试检查物理规则、角色限制、章节进度、历史存档迁移和无敌解锁。路线脚本通过普通移动、跳跃及对应操作模拟关卡。`qa/pixel-route.mjs`、`qa/sky-route.mjs`、`qa/route.mjs`、`qa/palace-route.mjs` 分别保留其他章节的路线检查。

可选浏览器脚本需要 Playwright 和本机 Microsoft Edge，例如 `qa/lab-browser-playthrough.cjs`、`qa/lab3d-browser.cjs` 和 `qa/lab3d-controls.cjs`。运行前应启动与脚本入口对应的服务器；使用原始 `dist/` 路径的脚本需注意上文的路由区别。测试结论以当次脚本输出与实际浏览器结果为准；布置场景、修改存档或启用无敌的功能检查，不能作为普通模式通关证明。

Three.js r169 使用 MIT 许可，完整许可证见 `dist/vendor/LICENSE.txt`。OpenAI SVG 来自 Simple Icons 11.15.0，图形文件按其 CC0 1.0 声明提供；CC0 不授予 OpenAI 品牌或商标权利，详情与链接见 `THIRD_PARTY_NOTICES.txt`。

本版本新增测试覆盖开箱唯一奖励、死亡清除强化、击杀不回血、账号隔离、API 重启恢复、云端当前关卡往返、全屏暂停和关内角色锁定。场景隔离的功能测试不作为普通通关证据。
开发原始路由可运行 `npm run dev`；发布合并目录用 `npm run build:web` 生成到 `.web`。

本机云存档开发：先设置 `MOSSLIGHT_DATA_DIR` 为未公开的私有目录，运行 `python backend/account_api.py`，再 `npm start`。服务端安装与备份见 `backend/README.md`。
Esc 在支持 Keyboard Lock 的全屏浏览器中会保持全屏并暂停；公网 HTTP 或其他不支持环境即使退出原生全屏，也立即暂停，点击继续重新进入全屏。

2.5.0 检查结果：117 项游戏逻辑测试、18 项真实 HTTP API 测试、20 项 3D 暂停/载档检查均通过。2D 另验证了关闭浏览器后重新登录精确恢复、四种视口及账号隔离；天宫/实验室各四种奖励箱位置均在不回血的普通规则下输入通关。

最终浏览器复验：2D 实验室通过真实 DOM 键盘按下/抬起、只读状态观察，以普通模式 285.7 秒零死亡完成 48 段、5 桥、5 存档点和 119 次击败，覆盖首领四种攻击；击杀不回血，最高生命仍为 6。
