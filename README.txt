## 角色、章节与解锁

2D 两名普通角色为「GPT（同人形象）」和「Claude」。GPT 使用用户提供的白紫龙娘参考形象；Claude 使用用户提供的橙色方块参考形象。两者使用相同的碰撞尺寸、跳跃高度和重力，具有不同的连斩数值、节奏、冲刺冷却、终结技能与像素特效。GPT 的月翼连斩伤害为 2 / 2 / 4，冲刺冷却 0.62 秒，终结技发出可贯穿两名敌人的月牙刃；Claude 的赤焰重击伤害为 3 / 3 / 6，冲刺冷却 0.70 秒，攻击节奏较慢，终结技产生双侧地面震波与更强的重击击退。以下角色解锁表适用于 2D；3D 使用固定白色方块，章节规则见下文。

| 阶段 | 条件 |
| --- | --- |
| 第一、第二章 | 默认开放 |
| 第三章 · 绯晶天宫 | 在当前版本累计通关前两章，顺序不限 |
| 第四章 · 星穹实验室 | GPT 和 Claude **各自**无辅助通关前三章，即六份独立角色记录 |
| 无敌模式 | 满足第四章前置条件后，由任一普通角色无辅助通关第四章 |
| 第三角色 · GPT（官方Logo） | 无敌模式已解锁且当前已开启时才可选择 |

一份角色通关记录要求整次挑战没有使用过无敌模式，也没有中途切换角色。中途关闭无敌或切回原角色，不会把这次挑战变成有效的普通通关；重新开始本关可开始新挑战。关卡内和暂停页禁止手动切换角色，只有返回选关页才能更换。Logo 形态关闭无敌时，会自动退回上一位普通角色，本次仍算辅助挑战。第三角色不参与普通解锁条件，也不能取得普通角色通关记录。

2D 与 3D 的通关、章节解锁和无敌偏好在同一账号中分别保存。2D 旧版前三章通关与有效最好成绩保留为历史记录，可保留第三章入口；历史记录不会自动给 GPT 或 Claude 补记通关，也不会直接解锁第四章或无敌模式。3D 将旧角色通关记录与历史普通通关合并为同一主角的章节进度，保留有效的第四章成绩；旧角色的进行中存档恢复为白色方块，使用过无敌或混合角色的标记仍保留。两版使用同一个旅人账号，云存档保存在服务器；本机缓存用于断网恢复，跨设备使用账号和密码登录。

## 账号与云存档

首次进入会自动注册并登录，生成旅人账号和 6 位数字密码。菜单账号栏可以查看、复制账号密码，也可以输入其他账号登录；不存在的账号会自动创建。已有账号必须使用正确密码。没有手机号、邮箱或第三方账号绑定，也不要求复杂密码。

暂停页的“保存存档”会保存当前角色、位置、收集、机关计时，以及 2D 的生命、开箱与攻击强化状态。选关页“继续存档”可恢复到暂停状态，再点击继续冒险。游戏每 15 秒自动保存，存档点、开箱、拾取强化和死亡时也立即保存。通关后清除对应关卡的进行中存档，保留账号通关记录。

账号数据保存在服务器 SQLite 数据库 `/var/lib/mosslight/account.sqlite3`，与静态版本目录分开，电脑或 API 重启、更新游戏均不会覆盖数据库。服务开机自启，每日生成经过完整性校验的备份；密码使用带盐 PBKDF2 哈希，服务器不保存明文密码。断网时保留账号对应的本机副本与待同步操作，网络恢复后上传。首次自动注册会导入当前浏览器的旧游戏进度；切换到已有账号以后以该账号的云端数据为准。

## 坠落与重生

2D 从 6 HP 开始。掉出地图后扣除 2 HP，回到离地前最后站立的平台；靠近边缘时，将身体完整放回平台并留出 32 像素内侧余量，已经位于内部的坐标保持不动。清除坠落速度并短暂无伤，保持收集、战斗、开箱、强化和机关时钟。恢复不会增加死亡次数。生命耗尽才调用原死亡规则，回到该关的存档点或唯一起点。

2D 每个站立帧都记录位置，包括平台边缘和塌落桥。窄平台的余量随宽度缩小；只调整当前平台内的坐标，不搜索更早的平台。移动平台使用当前高度，塌落桥在原处提供新的站立窗口。位置历史、HP 和坠落次数随当前关卡存档保存。存档点仍回复生命，击败敌人不回血。

3D 没有 HP、扣血预算或生命条。掉出地图及触碰致命机关时，立即按原规则回到最近存档点；第三、第四章只有起点存档，挑战重启并重置该次收集与机关。旧 3D 存档可以继续读取，已移除的 HP 与落脚历史字段会被忽略，不再写入新存档。按 R 返回存档点仍按原规则处理。

## 标题与背景音乐

两版名称统一为「苔光跃迁 · MOSSLIGHT 2D」与「苔光跃迁 · MOSSLIGHT 3D」。森林、夜城、天宫和实验室各有原创循环 BGM，包含旋律、和声、低音及适合场景的节奏层；2D 首领战有更紧凑的配器。音乐由随游戏打包的 Web Audio 乐谱生成，无外部音频请求。首次游玩操作后启动声音，声音按钮控制音乐与音效；暂停、通关及页面隐藏时音乐停止，继续后恢复。3D 的物理、关卡、主角、存档点与无生命值规则保持原样。

## 命中反馈

2D 实际命中触发短促卡肉：普通斩击约 65 毫秒、重击约 95 毫秒、击杀约 125 毫秒，Claude 额外有 8 毫秒重量感。月牙刃也使用终结技的反馈力度。命中期间战斗物理与跟随镜头短暂停顿，背景音乐持续播放，跳跃与连斩输入仍可排队；多目标命中的停顿取最大值，不叠加累积。空挥不会触发卡肉。轻微震屏采用衰减回弹，画面偏移每轴最多 3 个画布像素；局部冲击闪光、像素撞击火花与分层撞击声强化接触感，3D 的所有运行文件保持 2.7.0 原样。

## 宝箱与攻击强化

每张 2D 地图有可互动宝箱，靠近后按 E、点击箱子，或点触屏“开箱”按钮。每个箱子在首次打开时独立随机：95% 空箱，显示“好像只是一个空箱子...”；5% 掉落攻击强化。没有每关保底，也没有唯一奖励箱限制。接触强化后普通连斩、角色终结技能及反弹弹丸伤害翻倍，重复获得不叠加；死亡或主动回存档点后强化消失，非致命坠落保留强化。已开箱的结果随存档保存，不会因载档或死亡重抽，多个未领取的强化会同时保留。旧存档已开箱结果保留，尚未打开的箱子遵循独立概率。

## 2D 像素版 · 双星远行

横向卷轴关卡结合像素背景、多层视差、晨光、夜雨、云海夕照与洁净的未来实验室。普通角色可使用二段跳、光刃三连斩、冲刺闪避和弹丸反击。手机提供移动、跳跃、攻击与冲刺按钮，横屏可看到更多路线；切出浏览器会自动暂停。

| 无敌飞行 | A / D 左右，W / 上方向键 / 空格上升，S / 下方向键下降 |

| 关卡 | 路线 | 敌人（含首领） | 收集物 | 存档灯（含起点） |

击败关底首领并抵达右侧光门即可通关；普通敌人和收集物可以绕过。第三段斩击伤害与击退更强，光刃可反弹敌方弹丸。存档灯回复生命，击败普通敌人和首领都不会回复生命。前两章与实验室生命耗尽后返回最近存档，保留本局收集、分数与已击败的普通敌人，首领恢复初始状态；重开本关重置本局进度。

绯晶天宫包含晶刺、移动晶锯、垂直光束与塌落晶桥，仅保留起点存档。死亡或返回存档会重置本次挑战的敌人、首领、机关、收集和分数。首领「绯晶裁决者」使用冲锋与多种弹幕，半血后加速。

星穹实验室是一座完整运转的研究设施，路线经过无菌接驳舱、量子计算廊、聚变反应区和欧米伽主控室。实验室包含光束、晶锯、尖刺、塌落桥与补给存档，关底首领为「欧米伽主脑」。机关按固定物理时钟运行，暂停时冻结。

无敌模式解锁后，可在当前挑战中开关：免疫伤害、自由飞行，普通角色每次攻击清除当前可见画面内的敌人（包括首领）及屏内弹丸。关闭后恢复重力与普通攻击；若角色位于实体平台内部，会被移到安全表面。使用过无敌的挑战不计普通通关。

第三角色「GPT（官方Logo）」以 OpenAI 标志为中心，带有旋转光针。它仅在无敌开启时可用，移动更快；光针接触敌人即可消灭敌人。右键 / K / Shift 可无限连续冲刺，每次冲刺清除当前可见画面内的敌人；左键 / J 触发自爆式全屏攻击。这里的“全屏”指当前可见游戏画面，屏外敌人保持原状；自爆是攻击效果，不会结束挑战。关闭无敌后退出该角色并恢复普通角色。

2D 版不依赖 Three.js。角色动作图集与四张背景使用内置 ImageGen 生成或编辑，提示词保存在 `dist/2d/assets/PROMPTS.json`；实验室另有 `dist/2d/assets/LAB-PROMPT.json`。Logo 使用有明确来源的 SVG 图形，地形、敌人、光针和战斗特效由 Canvas2D 绘制，音乐与音效由 WebAudio 合成。

## 3D 版

3D 版保留无战斗的机关平台跳跃：越过浮岛与测试平台，收集微光和珍藏，抵达圆形光门。主角固定为原白色竖立方块，菜单和暂停页均无选角。普通模式通关森林与都市解锁天宫，通关前三章解锁实验室，普通通关全部四章解锁无敌模式。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键，方向跟随镜头 |
| 环视 / 缩放 | 移动鼠标 / 滚轮 |
| 跳跃 | 空格 |
| 暂停并释放鼠标 | Esc |
| 继续并重新锁定鼠标 | 点击“继续冒险” |
| 视角复位 / 辅助转向 | C / Q、E |
| 回到最近存档点 | R |
| 切换已解锁的无敌模式 | G，或界面开关 |
| 无敌飞行 | WASD 水平移动，空格上升，Shift 下降 |

点击出发会请求全屏与鼠标锁定；浏览器需要用户点击才允许这些功能。若未获得锁定，可点击画面重试。返回选关退出全屏。手机使用左侧摇杆、跳跃按钮、空白区域单指环视与双指缩放；无敌开启时提供上升和下降控制。

森林包含 22 个平台和自转浮岛；都市包含 30 个平台与移动、塌落、光栅、旋转光臂、下压闸门和间歇平台。前两章有途中存档，失败保留已收集物品和积分。微光计 10 分、珍藏计 50 分，收集不影响通关；任意关全收集可解锁金色光环。

绯晶天宫包含 44 个平台、运动机关与完整云上宫殿。星穹实验室包含 50 个测试平台，场景由研究舱室、通道、设备与核心装置组成。两章均只有起点存档，生命耗尽或触碰致命机关后从起点重新挑战并重置本次收集和机关；普通坠落按安全落脚点规则恢复。

无敌解锁后提供机关免疫与自由飞行，主角仍为白色方块。关闭无敌后恢复重力和碰撞，使用过无敌的本次挑战不计普通通关。

## 本地运行与目录

安装 Node.js 20 或更新版本，在项目目录运行：

```sh
node server.mjs
```

默认打开 `http://127.0.0.1:4186/` 进入 2D；`http://127.0.0.1:4186/3d/` 进入 3D，两版可从菜单互跳。运行不需要安装依赖，素材和 Three.js 随源码提供；本地服务器启动后可离线游玩。ES 模块需要 HTTP 服务，请不要直接双击 HTML。

`server.mjs` 的默认展示路径与原始静态目录不同：开发源目录仍是 `dist/index.html` 对应 3D、`dist/2d/index.html` 对应 2D。直接用其他静态服务器托管 `dist/` 时，根路径是 3D，`/2d/` 是 2D；部署或编写浏览器测试时需使用对应路由。

| 文件 | 内容 |

```sh
npm test
node qa/lab-route.mjs
node qa/lab3d-route.mjs
```
